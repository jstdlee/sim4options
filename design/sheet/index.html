How to use Kon in the app

Use <FoxSticker pose="cheer" :size="96" say="Nice!" />. The component adds the white sticker outline and the manga speech bubble. Add bob for a slow idle sway, which turns off when the viewer asks for reduced motion.

To add a pose, add a line to design/jobs_poses.txt, run design/edit.sh with the master design, then run design/cutout.py.
